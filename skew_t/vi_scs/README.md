# VI-tuned sub-Cauchy coupling: 1,000 replicates

This experiment independently fits the sub-Cauchy transformation, tunes its proposal step, and runs 1,000 SCS pairs. The comparison also includes 1,000 DCS, Euclidean and stereographic pairs each, using common Euclidean initial states. `previous_meeting_times.csv` supplies only the 3,000 observations for those other three methods.

The median uses the first empirical survival crossing of 0.5; the usual two-central-order-statistic median for DCS is 1,342. Restricted means retain censored pairs at the cutoff. The bootstrap seed is 26093006, with 10,000 paired resamples. Intervals condition on the frozen fits and tuning.

The mean DCS-to-SCS ratio is 41.393 (paired 95% interval: 38.924–43.870). VI optimizes a density-approximation objective rather than the coupling meeting time.

## SCS transformation and fitted parameters

As in Section 3 of the [SCS paper](https://arxiv.org/pdf/2601.11066), the observer latitude is fixed at ℓ = 1.1. Its horizontal component h_o, the location vector μ, and scalar scale R are fitted. This is 201 parameters, matching the number in the retained DCS fit. It is the scalar-scale family used in the reference, not a full covariance model. The horizontal observer h_o is distinct from the proposal step size h.

| Parameter | Fitted value |
|---|---:|
| R | 1.3270881757184056 |
| μ₁, μ₂ | 0.22691929348637013, −0.2275854923770679 |
| ||μ|| | 0.3217474116762721 |
| (h_o)₁, (h_o)₂ | −0.17719965437773905, 0.17719659589690273 |
| ||h_o|| | 0.2506029123081874 |
| cos(h_o, α) | −0.9999723845511626 |
| Observer distance from sphere center | 0.2698181232929787 |
| Proposal step h | 0.08 |

All 100 entries of μ and h_o are in `scs_parameters.json`. Small nonzero entries beyond the first two coordinates are retained from the stochastic fit; they were not rounded to zero. The positive radius and constrained observer are represented by R = exp(ζ) and h_o = sqrt(1 − (ℓ−1)²) tanh(||v||)v/||v||, with its continuous extension at v = 0.

The implementation uses centered unit-sphere coordinates z = (u,t). Its bright side is t < b, where b = ℓ−1 = 0.1. The paper's coordinates are z + e₁₀₁. The map and surface Jacobian are

Fθ(z) = μ + R[ℓu − (1+t)h_o]/(b−t),

log Jθ(z) = d log(Rℓ) + log(1−bt−h_oᵀu) − (d+1)log(b−t).

The sphere target is proportional to π(Fθ(z))Jθ(z). The cap does not depend on μ, R or h_o, so its uniform distribution is a fixed base distribution for pathwise stochastic gradients. The Jacobian is a determinant on an orthonormal tangent basis, not an ambient rectangular determinant.

## Variational fitting and step selection

We minimize E[-log π(Fθ(Z)) − log Jθ(Z)] over Z uniform on the fixed bright cap. This differs from KL(qθ || π) only by constants independent of θ. It follows SCS Section 3, Equation (7), and the fixed-base reverse-KL principle in [DCS Appendix D](https://arxiv.org/pdf/2608.04284), Equation (32).

SCS is initialized at μ = 0, h_o = 0 and R = 10/11. It uses seed 26093001, 4,000 Adam iterations, and 2,048 fresh IID uniform-cap samples per iteration, generated by exact rejection. Adam uses β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸, and learning rates 0.01 for 3,000 iterations and 0.002 for 1,000 iterations. This matches the optimizer budget and selection rule of the retained DCS fit. The cap and ball are different base distributions; matching parameter counts and optimization budgets does not make the transformation families identical.

The final iterate and mean of the last 500 unconstrained iterates were evaluated on 20,000 independent cap samples (seed 26093501). The mean iterate was selected. The unnormalized held-out objective decreased from 79.1594 to −27.7306. These raw values omit constants and are not absolute KL divergences. The holdout is used only for fit selection, with no selection by observed meeting times.

The proposal step is selected separately using 40,000 exact stationary skew-t draws (seed 26093002). The nearest point to 40% on the saved grid was h = 0.08, with estimated acceptance 40.742%. A fresh independent check (seed 26093003; 40,000 draws) gave 40.303% with Monte Carlo standard error 0.189 percentage points; dark-side rejection was 5.955%. The grid and every estimate are in `scs_stationary_step_tuning.csv`. The fitted DCS proposal remains γ/R = 0.14, with stationary acceptance 39.962%. No fit or tuning occurs during the meeting-time runs.

## Target, starting pairs and coupling

The target is unchanged: the Azzalini–Capitanio skew-t with d = 100, ν = 2, ξ = 0, Ω = I and α = (100, −100, 0, …, 0), using the Student-t CDF skewing factor T₁₀₂. The DCS reference's ν = 3 experiment is not being reproduced verbatim; both fitted transformations here target ν = 2.

The exact same 1,000 Euclidean initial pairs are in `initial_states.npz`. They were generated previously by sampling independent uniform bright-side states under the original SCS map with μ = 0, horizontal observer 0, ℓ = 1.1 and R = 10/11. New SCS initial sphere states are obtained by applying the inverse of the fitted map to those Euclidean pairs, and are saved in `scs_fitted_initial_states.npz`. These fitted sphere states are not claimed to be uniform. Retaining common Euclidean starts permits comparison with the unchanged three other methods.

The coupled proposal is spherical maximal reflection, with tangent Gaussian standard deviation h = 0.08 and a shared Metropolis uniform. Each chain rejects its own dark-side proposal; there is no stepping out and no redrawing until a bright-side point is proposed. The meeting rule is exact coalescence, with zero lag, no burn-in and a cap of 10⁶ iterations. For every replicate i = 0,…,999, the JAX key is fold_in(key(26092913), i), retaining the previous SCS seed convention.

## Plot interpretation and validation

The two-panel style is retained from the user's edited plotting script. The histogram is conditional on meeting by the cap; the survival curve retains the censored pairs. The curve is labelled meeting-time survival and is not asserted to bound TV distance to stationarity for these two nonstationary, zero-lag starts.

Legend acceptance is the unweighted average of the individual chains' acceptance fractions before meeting or censoring. VI-SCS's legend rate is 44.114%; pooling all its proposals gives 40.575%. Its independent stationary estimate is 40.303%. These statistics have different definitions. The DCS legend rate remains 39.712%.

The generalized inverse and map were checked on all 2,000 saved initial states and 1,000 independent target states, with maximum relative roundtrip error 1.88×10⁻¹⁴. The surface Jacobian agrees with automatic differentiation to 1.43×10⁻¹³ in log scale, and the objective's directional derivative agrees with a central finite difference to 2.52×10⁻¹⁰. The general-observer kernel reduces to the original axial-observer implementation at the previous parameters; batched and scalar simulation counts also agree. See `scs_validation.json`. `data_validation.json` checks all 4,000 final rows and confirms that the 3,000 other-method rows are unchanged.

## Files and reproduction

- `meeting_times_vi_1000.pdf` and `.png`: updated figure.
- `manuscript_text.md`: reusable methods paragraph, optional implementation detail, results and caption.
- `meeting_times.csv`: final 4,000 observations; `scs_vi_meeting_times.csv`: 1,000 new SCS rows.

- `previous_meeting_times.csv`: 3,000 DCS, Euclidean and stereographic observations used as fixed inputs to the final comparison.
- `dcs_complete_configuration.json`: retained DCS fit and coupling settings.

Using Python 3.12 and the packages in `requirements.txt`, run:

```sh
python scs_vi_experiment.py --stage fit
python scs_vi_experiment.py --stage tune
python scs_vi_experiment.py --stage validate
python scs_vi_experiment.py --stage run
python summarize_results.py
python plot_meeting_times.py
```

For sampling at the saved fit, omit `fit` and `tune`. The meeting runner resumes completed rows in `scs_vi_meeting_times.csv`; to recompute them, use a fresh copy without that output file. To reproduce only the plot, run the last command using the saved final data. DCS, Euclidean and stereographic observations are supplied in `previous_meeting_times.csv`; the shared target, DCS fit and coupling kernels are in `coupling_experiment.py`. The commands above rerun VI-SCS and merge it with those saved observations. Exact floating-point trajectories may vary across platforms.
