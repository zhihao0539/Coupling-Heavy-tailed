# NBA salary: fitted SRWM, DCS and RWMH couplings

This experiment uses the existing Student-t regression target in `target.py`:
standardized predictors and response, no added intercept, Student-t errors
with 4 degrees of freedom and independent coefficient priors with 83 degrees
of freedom. The 82-dimensional sampled state is `(coefficients, v)`, where
`v=sinh(log(sigma))`; the target includes the coordinate Jacobian.

All methods use the same 1,000 saved initial pairs in `initial_states.npz`.
These were generated by projecting independent uniform sphere points through
the fitted stereographic map, not by drawing from the target. Each pair stops
at meeting or the 2,000,000-step cutoff.

## Variational fitting

`run_vi.py` has separate `fit_stereographic`, `fit_dcs` and `fit_euclidean`
functions using the shared generic VI runners. Its current `main()` fits
only the new Euclidean preconditioner and preserves the completed SRWM and
DCS fits. Their functions remain available for an explicit refit.

RWMH fits a full Gaussian by reverse KL, learning both `mu` and the full
lower-triangular `preconditioning_matrix` L. It starts from `mu=0.25` in
every coordinate and `L=I`, with no fixed fitted fields. It uses 4,000 Adam
updates, batches of 2,048, a 20,000-draw holdout and averaging of the final
500 parameter vectors. Rates are 0.01 then 0.002 after update 3,000, and the
seed is 26092803. The fit is stored under `euclidean` in the existing
`fitted_parameters.json`, alongside SRWM and matrix DCS.

RWMH freezes the fitted affine map `x=mu+Lz`, whitens the common initial
states, and runs the standard Euclidean maximal-reflection coupling against
`log_density(mu+Lz)+log det L`. The Jacobian is constant during sampling.
The scalar proposal step in whitened coordinates is `EUCLIDEAN_H=0.265`.
Independent 64-pair calibration and 100-pair validation gave 23.22% and
23.39% acceptance, respectively. Acceptance is averaged through meeting or
cutoff. Calibration code and detailed records stay in the external workspace.

SRWM learns its location and full matrix; its step remains 0.1. Matrix DCS
learns location, matrix and beta; its fitted beta remains 3.252823847717482
and its unit-ball step remains 0.049. Their completed fits and samples were
preserved when RWMH was added.

## Run

The supplied fits and results are complete. To refit RWMH only:

```sh
python student_t_regression/nba_salary/run_vi.py
```

To generate a fresh comparison of all three methods:

```sh
python student_t_regression/nba_salary/run_experiment.py
```

Refitting a map can require recalibrating its step size. The short method
functions in `run_experiment.py` can also be called separately. To redraw
the saved comparison without simulation:

```python
import pandas as pd
from student_t_regression.nba_salary.run_experiment import OUTPUT, plot_comparison
plot_comparison(pd.read_csv(OUTPUT))
```

The comparison uses logarithmic time axes. RWMH is orange, stereographic is
blue and DCS is purple. No isotropic RWM baseline is included.
